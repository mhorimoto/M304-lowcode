# M304 EEPROM ユーティリティ (dump304 / a2sender)

UECS対応制御ノード「M304」の内蔵EEPROM領域に対して、HTTPインターフェース経由で設定値の読み出し（ダンプ・可読化）および生データの取得、書き込みを行うためのツール群です。

M304 ファームウェア Version 3.x.x および Version 2.x.x に対応しています。

---

## 収録スクリプト一覧

| スクリプト名 | 説明 |
| :--- | :--- |
| `dump304` | M304のEEPROM各領域をHTTP経由で読み出し、HEXダンプまたはパース済みの可読テキスト（CSV/表形式）で出力します。 |
| `a2sender` | M304の特定エンドポイント（URL）にアクセスし、EEPROMメモリ等のダンプ結果を取得・表示します。 |

---

## 動作要件

* **PHP 7.4 / 8.x**（CLI環境）
* PHPの `allow_url_fopen` が有効であること（`fopen("http://...")` によるHTTPアクセスを使用）
* 対象のM304ノードとネットワーク疎通（HTTPポート80）が可能であること

## 1. dump304

### 概要

M304のWebインターフェース（`http://<ホスト>/L00<アドレス>`）を介してEEPROMデータを取得し、生ダンプの整形表示または内部構造（ノード基本情報、ファームウェア/パラメータバージョン、送受信設定、スケジュール、条件判定式など）をパースして表示します。

### 書式

```bash
./dump304 -d <領域> [-u] [-2] <M304のIPアドレスまたはホスト名>
```

### オプション一覧

| オプション | 必須/任意 | 説明 |
| :--- | :---: | :--- |
| `-d <領域>` | **必須** | 読み出すEEPROM領域を指定します（`info`, `rx`, `sched`, `tx`, `ope`）。 |
| `-u` | 任意 | **人間に可読しやすい形式（パース表示）** で出力します。省略時は標準的なHEXダンプを出力します。 |
| `-2` | 任意 | **M304 Version 2.x.x** 用のデータ構造としてパースします。省略時はデフォルトで **Version 3.x.x** として処理します。 |
| `<ホスト名>` | **必須** | 対象となるM304のIPアドレス（例: `192.168.0.226`）またはホスト名。 |

### 対象領域 (`-d` のパラメータ)

| 指定値 | 対象領域 | 開始アドレス | 説明 |
| :--- | :--- | :---: | :--- |
| `info` | ノード基本情報・バージョン | `0x0000` | MAC、UECS-ID、IP設定、各種バージョン、ノード名等 |
| `rx` / `sched` | 受信・スケジュール設定 | `0x1000` | スケジュール条件、リレー制御論理、比較式等（最大30エントリ） |
| `tx` | 送信設定 | `0x3000` | CCMタイプ、送信周期、優先度、送信条件等（最大10エントリ） |
| `ope` | 演算/条件定義 | `0x5000` | 条件判定・演算比較設定（最大10エントリ） |

### 使用例

#### (1) ノードの基本設定情報・バージョンを可読表示する

```bash
./dump304 -d info -u 192.168.0.226
```

**出力例:**
```text
     UECS-ID: 00100C00000B
 F/W VERSION: M304 Ver3.2.@8
PARAM VERSION: NONE (Not set)
 MAC ADDRESS: 02:A2:73:0B:00:26
   IP ASSIGN: STATIC
    FIXED IP: 192.168.0.226 
     NETMASK: 255.255.255.0 
     GATEWAY: 192.168.0.1 
         DNS: 192.168.0.1 
      VENDER: YS-Lab
   NODE NAME: M304-lowcode-01
   DEBUG MSG: 00000000
```
* **F/W VERSION**: EEPROM `0x7FF0` から始まる16バイト（`0x00` または `0xFF` 終端）を取得して表示。
* **PARAM VERSION**: EEPROM `0x7FE0` から始まる16バイトを取得して表示。未書き込み（All `0xFF`）の場合は `NONE (Not set)` と表示。

#### (2) 受信/スケジュール設定を可読表示する (Version 3.x.x)

```bash
./dump304 -d rx -u 192.168.0.226
```

**出力形式 (v3):**
```text
エントリ番号:有効フラグ,開始時刻,終了時刻,時間単位,周期,継続時間,リレー1〜8状態,比較式0〜4...
```

#### (3) 生のHEXダンプを取得する

`-u` オプションを外すと、ASCII文字併記のHEXダンプを出力します。

```bash
./dump304 -d info 192.168.0.226
```

**出力例:**
```text
0x0000: 00 10 0C 00 00 0B 02 A2 73 0B 00 26 00 FF FF FF  ..........&.....
0x0010: C0 A8 00 E2 FF FF FF 00 C0 A8 00 01 C0 A8 00 01  ................
...
```

#### (4) Version 2.x.x のM304を対象とする場合

`-2` オプションを付与して実行します。

```bash
./dump304 -d rx -u -2 192.168.0.200
```

## 2. a2sender

### 概要

M304の内部メモリ・ダンプ用エンドポイントURLを直接指定してアクセスし、HEXダンプデータをASCII変換付きで取得・整形表示する簡易ユーティリティです。

### 書式

```bash
./a2sender <対象URL>
```

### 使用例

```bash
# アドレス 0x0000 からのデータを直接取得
./a2sender http://192.168.0.226/L000000

# バージョン領域（0x7F00）を直接取得
./a2sender http://192.168.0.226/L007F00
```

## EEPROM メモリアドレス仕様 (抜粋)

| アドレス範囲 | サイズ | 用途・格納データ |
| :--- | :---: | :--- |
| `0x0000 - 0x007F` | 128B | ノード基本情報（UECS-ID, MAC, IP設定, ベンダー名, ノード名等） |
| `0x1000 - 0x17FF` | 2KB | 受信設定・スケジュール設定（最大30エントリ） |
| `0x3000 - 0x32FF` | 768B | 送信設定（最大10エントリ） |
| `0x5000 - 0x51FF` | 512B | 演算・条件判定設定（最大10エントリ） |
| `0x7FE0 - 0x7FEF` | 16B | **PARAM VERSION**（パラメータバージョン文字列、未設定時はAll `0xFF`） |
| `0x7FF0 - 0x7FFF` | 16B | **F/W VERSION**（ファームウェアバージョン文字列、例: `M304 Ver3.2.@8`） |

---

## 内部通信仕様 (HTTPコマンド)

M304ノードはHTTP GETリクエストを受け取ることで、内蔵EEPROMおよびメモリの入出力を行います。

* **読み出し (Read):**
  * `http://<IP>/L00<ADDR>`
  * アドレスは16進数で指定します（例: `0x1000` 番地を読み出す場合 `http://<IP>/L001000`）。
  * 1リクエストあたり256バイト単位（16バイト×16行）でテキスト形式のHEXデータが返却されます。
